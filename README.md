# Telegram Bot — Dr. Shoxruz XDENT Dental Clinic

Цифровая приемная для премиальной стоматологической клиники **"Dr. Shoxruz XDENT Dental Clinic"** (г. Ташкент), разработанная на базе **Python 3** и **aiogram 3.x**.

Бот полностью автоматизирует первичный сбор данных пациентов (ФИО, год рождения, район проживания, номер телефона) для заведения медицинской карты и мгновенно оповещает администраторов в рабочий Telegram-чат.

---

## 🚀 Основные возможности

1. **Главное меню (`/start`)**:
   - Приветствие пациента.
   - Разделы: «🦷 Услуги и цены», «👨‍⚕️ Наши врачи и направления», «📝 Записаться на прием», «📍 Локация и контакты».
2. **Услуги и прозрачные цены**:
   - Первичная консультация и диагностика (Консультация + снимок — 150 000 сум, при продолжении лечения бесплатно).
   - Терапия и чистка (Проф. гигиена, лечение кариеса).
   - Ортодонтия (Брекеты, элайнеры — от первичного осмотра).
   - Хирургия и имплантация (Удаление, импланты под ключ).
   - Детская стоматология.
   - Быстрый переход к записи на конкретную услугу (`[Записаться на эту услугу]`).
3. **Информация о врачах**:
   - Главный врач (хирург-имплантолог), Терапевт, Ортодонт, Детский врач.
4. **Локация и контакты**:
   - г. Ташкент, пр-т Мирзо Улугбека.
   - Режим работы: 24/7 (круглосуточно).
   - Телефон клиники: `+998 95 111 11 61`.
   - Автоматическая отправка нативной точки геолокации Telegram.
5. **Автоматизированный сбор анкеты пациента (FSM)**:
   - Шаг 1: Услуга / жалоба.
   - Шаг 2: ФИО пациента (валидация).
   - Шаг 3: Год рождения (валидация диапазона 1920–текущий год).
   - Шаг 4: Район проживания / ориентир.
   - Шаг 5: Номер телефона (`KeyboardButton(request_contact=True)` + ручной ввод).
   - Возможность отмены записи на любом шаге (`/cancel` или кнопка «❌ Отменить запись»).
6. **Оповещение администраторов**:
   - Отправка структурированной карточки лида в `ADMIN_CHAT_ID`:
     ```html
     🦷 НОВАЯ ЗАПИСЬ НА ПРИЕМ (XDENT)
     👤 Пациент: Каримов Тимур (@username)
     📅 Год рождения: 1995
     📍 Адрес: Мирзо-Улугбекский р-н
     🛠 Услуга: Терапия и чистка
     📞 Телефон: +998901234567
     ⏱ Время заявки: 21.09.2026 11:15:00 (Ташкент)
     ```

## 🛠 Установка и запуск

### 1. Клонирование / переход в директорию
```bash
cd /Users/khamid/Documents/Xdent
```

### 2. Создание виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate  # На Linux/macOS
# venv\Scripts\activate   # На Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Заполните параметры в файле `.env`:
```ini
BOT_TOKEN=your_bot_token_from_botfather
ADMIN_CHAT_ID=your_telegram_chat_or_group_id
```

### 5. Запуск бота локально (Polling)
```bash
python3 main.py
```

## ⚡ Деплой на Vercel (Serverless Webhook)

Бот полностью подготовлен для деплоя на [Vercel](https://vercel.com):
- Точка входа вебхука: `api/index.py`
- Конфигурация: `vercel.json`

### Шаги деплоя:
1. Зайдите на [Vercel Dashboard](https://vercel.com/dashboard) и нажмите **Add New Project**.
2. Выберите ваш GitHub-репозиторий `xdent-dental-bot` (или импортируйте его).
3. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN`: токен вашего бота от @BotFather
   - `ADMIN_CHAT_ID`: ID чата или группы администраторов
4. Нажмите **Deploy**.
5. После успешного деплоя Vercel выдаст домен (например: `https://xdent-dental-bot.vercel.app`).
6. Установите вебхук в Telegram, открыв в браузере или выполнив команду:
   ```bash
   curl -F "url=https://<ВАШ_ДОМЕН_VERCEL>/api/index" https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/setWebhook
   ```
   *(Замените `<ВАШ_ДОМЕН_VERCEL>` и `<ВАШ_BOT_TOKEN>` на ваши реальные значения).*
